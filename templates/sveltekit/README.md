This repo contains a template you can copy for using svelte-draw with [SvelteKit](https://svelte.dev/docs/kit) (a client-side SPA, since the editor is browser-only).

## Local development

Install dependencies with `npm install`.

Run the development server with `npm run dev`.

Open `http://localhost:5173/` in your browser to see the app.
