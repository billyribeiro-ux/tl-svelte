# Contributing

We are **not accepting contributions** to svelte-draw at this time. Pull requests are turned off for this repository.

For more details on this policy, see this issue.

## Create an issue instead

If you have found a bug, have a feature request, or want to suggest a change, please create an issue. Issues are the best place to discuss proposed changes with the team, and we read every one.

If a code example would help the discussion, fork the repository and link to your branch in the issue.

Please also see our Code of Conduct for our expectations around community culture.
