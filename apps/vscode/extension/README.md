## Introduction

svelte-draw is a very good whiteboard for the web. This extension will let you use svelte-draw inside of VS Code, using offline `.tldr` files. Create drawings, diagrams, or visual documentation, and then commit the files alongside your code!

!A screenshot of svelte-draw in VS Code

## Usage

- To create a new svelte-draw file, use the provided command: "svelte-draw: New svelte-draw File".

!A recording of opening svelte-draw in VS Code

- To view an existing svelte-draw file, open a file with the `.tldr` extension in VS Code.

> **Tip:** The `.tldr` files you create with this extension can also be opened in the svelte-draw web app. You can also use this extension to open `.tldr` files saved from the web app.

## Releases

This extension is automatically released to the VS Code Marketplace when changes are merged:

- **Pre-releases**: Merges to `main` branch trigger pre-release builds
- **Production releases**: Merges to `production` branch trigger stable releases

### Direct Downloads

You can also download the extension directly from our repository:

- **Latest Production Release**: svelte-draw-vscode.vsix (from `production` branch)

To install from a `.vsix` file:

1. Download the file from the link above
2. Open VS Code
3. Go to Extensions (Ctrl+Shift+X)
4. Click the "..." menu and select "Install from VSIX..."
5. Select the downloaded `svelte-draw-vscode.vsix` file
