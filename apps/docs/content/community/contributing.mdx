svelte-draw's source code is available on GitHub at github.com/billyribeiro-ux/tl-svelte. While you can read the code, we are not accepting external contributions.

The best way to help improve svelte-draw is to share your feedback. To report a bug or request a feature, open an issue on GitHub or let us know on Discord. If a code example would help the discussion, please fork the repository and link to your branch in the issue.
