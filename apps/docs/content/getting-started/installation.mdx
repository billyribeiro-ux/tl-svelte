To use the svelte-draw SDK, first install the `svelte-draw` package:

```bash
npm install svelte-draw
```

Now import and use the [SvelteDraw](?) component inside of any Svelte 5 component.

```svelte
<script lang="ts">
	import { SvelteDraw } from 'svelte-draw'
	import 'svelte-draw/svelte-draw.css'
</script>

<div style="position: fixed; inset: 0">
	<SvelteDraw />
</div>
```

### Wrapper

The [SvelteDraw](?) component must be wrapped in a parent container with an explicit size. Its height and width are set to `100%`, so it will fill its parent container.

### Accessing the editor

Use the `onMount` prop to access the [Editor](?) instance when it's ready:

```svelte
<script lang="ts">
	import { SvelteDraw } from 'svelte-draw'
</script>

<div style="position: fixed; inset: 0">
	<SvelteDraw
		onMount={(editor) => {
			// Do something with the editor
			editor.selectAll()
		}}
	/>
</div>
```

The callback can return a cleanup function that runs when the editor unmounts.

### CSS

In addition to the [SvelteDraw](?) component itself, you should also import the `svelte-draw.css` file from the `svelte-draw` package.

```ts
import 'svelte-draw/svelte-draw.css'
```

You can alternatively import this file inside of another CSS file using the `@import` syntax.

```css
@import url('svelte-draw/svelte-draw.css');
```

If you'd like to deeply change the way that svelte-draw looks, you can copy the `svelte-draw.css` file into a new CSS file, make your changes, and import that instead.

### Fonts

The svelte-draw SDK bundles its own fonts for shapes: IBM Plex (Sans, Serif, Mono) and Shantell Sans (for draw-style text). These are loaded automatically from the CDN or self-hosted [static assets](#Static-assets).

The svelte-draw UI will inherit its font family. You can set this to any font you like. For example, to use Inter:

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@500;700&display=swap');

.tl-container {
	font-family: 'Inter', sans-serif;
}
```

### HTML

If you're using the [SvelteDraw](?) component in a full-screen app, update your HTML page's meta (in SvelteKit, `src/app.html`) viewport element as shown below.

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />
```

Without these viewport options, some features like safe area positioning won't work correctly.

```svelte
<SvelteDraw licenseKey={YOUR_LICENSE_KEY} />
```

## Static assets

To use the [SvelteDraw](?) component, the app must be able to find certain assets. These are contained in the `embed-icons`, `fonts`, `icons`, and `translations` folders. We offer a few different ways of making these assets available to your app.

### Using a bundler

If you're using a bundler like webpack or rollup, you can import the assets directly from the `@svelte-draw/assets` package. Your bundler will copy the assets with your bundle and insert the correct URLs in their place.

There are three options:

- `import {getAssetUrlsByImport} from '@svelte-draw/assets/imports'`: import asset files using import statements. You'll need to configure your bundler to treat imports of .svg, .png, .json, and .woff2 files as external assets.
- `import {getAssetUrlsByImport} from '@svelte-draw/assets/imports.vite'`: import asset files, appending `?url` to the asset path. This works correctly with [vite](https://vitejs.dev/guide/assets#explicit-url-imports) without any extra configuration needed.
- `import {getAssetUrlsByMetaUrl} from '@svelte-draw/assets/urls'`: get asset urls using `new URL(path, import.meta.url)`. This is a standards-based approach that works natively in most modern browsers & bundlers.

Call the function, and pass the resulting `assetUrls` into the `SvelteDraw` component:

```svelte
<script lang="ts">
	import { getAssetUrlsByMetaUrl } from '@svelte-draw/assets/urls'
	import { SvelteDraw } from 'svelte-draw'

	const assetUrls = getAssetUrlsByMetaUrl()
</script>

<SvelteDraw {assetUrls} />
```

### Using a public CDN

By default, we serve these assets from a public CDN. This works without configuration and is a good starting point.

If you would like to customize some of the assets you can pass the customizations to our [SvelteDraw](?) component. For example, to use a custom icon for the `hand` tool you can do the following:

```svelte
<script lang="ts">
	import { SvelteDraw } from 'svelte-draw'

	const assetUrls = {
		icons: {
			'tool-hand': './custom-tool-hand.svg',
		},
	}
</script>

<SvelteDraw {assetUrls} />
```

This will use the custom icon for the `hand` tool and the default assets for everything else.

### Self-hosting assets

You can also host these assets yourself:

1. Download the `embed-icons`, `fonts`, `icons`, and `translations` folders from the assets folder of the svelte-draw repository.
2. Place the folders in your project's public path.
3. Pass `assetUrls` prop to our `<SvelteDraw/>` component to let the component know where the assets live.

You can use our `getAssetUrls` helper function from the `@svelte-draw/assets` package to generate these urls for you.

```svelte
<script lang="ts">
	import { getAssetUrls } from '@svelte-draw/assets/selfHosted'
	import { SvelteDraw } from 'svelte-draw'

	const assetUrls = getAssetUrls()
</script>

<SvelteDraw {assetUrls} />
```

While these files must be available, you can overwrite the individual files: for example, by placing different icons under the same name or by modifying or adding translations.

If you use a CDN for hosting these files you can specify the base url of your assets. To recreate the above option of serving the assets from our CDN you would do the following:

```ts
import { getAssetUrls } from '@svelte-draw/assets/selfHosted'
import { getDefaultCdnBaseUrl } from 'svelte-draw'

const assetUrls = getAssetUrls({
	baseUrl: getDefaultCdnBaseUrl(),
})
```

## Subcomponents

The [SvelteDraw](?) component combines two lower-level components: [SvelteDrawEditor](?) and [SvelteDrawUi](?). If you want more granular control, you can use those lower-level components directly. See the [exploded example](/examples/configuration/exploded) for reference.

### Customizing components

You can customize the appearance of the svelte-draw editor and UI using the [SvelteDraw](?) (or [SvelteDrawEditor](?)) component's `components` prop. This prop accepts a [TLComponents](?) object, which combines [TLEditorComponents](?) (canvas-level components like the background and grid) with [TLUiComponents](?) (UI elements like toolbar, menus, and panels).

Each entry is a Svelte component:

```svelte
<script lang="ts">
	import { SvelteDraw, type TLComponents } from 'svelte-draw'
	import YourCustomBackground from './YourCustomBackground.svelte'
	import YourCustomGrid from './YourCustomGrid.svelte'
	import YourCustomToolbar from './YourCustomToolbar.svelte'
	import YourCustomMainMenu from './YourCustomMainMenu.svelte'
	import YourCustomStylePanel from './YourCustomStylePanel.svelte'
	import YourCustomContextMenu from './YourCustomContextMenu.svelte'

	const components: TLComponents = {
		// Editor components
		Background: YourCustomBackground,
		Grid: YourCustomGrid,

		// UI components
		Toolbar: YourCustomToolbar,
		MainMenu: YourCustomMainMenu,
		StylePanel: YourCustomStylePanel,
		ContextMenu: YourCustomContextMenu,
	}
</script>

<SvelteDraw {components} />
```

Canvas overlay elements like the selection foreground, brush, snap indicators, and scribble are rendered via the [OverlayUtil](?) system rather than Svelte components. You can customize them by extending the built-in overlay utils and passing them via the `overlayUtils` prop.

See the [TLEditorComponents](?) and [TLUiComponents](?) type definitions for the complete list of customizable components.
